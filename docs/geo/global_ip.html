💡 グローバルIPアドレスとは？

グローバルIPアドレスは、インターネット上でお使いのデバイス（またはルーター）を一意に識別するアドレスです。Wi-Fi・モバイル回線・VPNの切り替えにより変化することがあります。

  • IPv4: 例) 203.0.113.1（32ビット、ドット区切り4つの数字）
  • IPv6: 例) 2001:db8::1（128ビット、コロン区切りの16進数）
  • VPN使用時: VPNサーバーのIPアドレスが表示されます
  • 共有回線: 同じWi-Fiを使う複数端末は同一のグローバルIPを持ちます

🔒 プライバシーについて

このツールでは、IPアドレスの取得・表示はすべてお使いのブラウザ上でのみ行われます。あなたのIPアドレスはこのサイトのサーバーには送信・記録されません。

データ出典:

このツールは、あなたが現在インターネットに接続する際に使用している「グローバルIPアドレス」をリアルタイムで確認できるサービスです。

グローバルIPアドレスとは、インターネット上であなたの端末（またはルーター）を識別するための番号です。自宅のWi-Fiやモバイル回線、VPNなど、接続環境が変わるたびに異なる値が割り当てられる場合があります。

【データの読み方】
表示される値は「xxx.xxx.xxx.xxx」形式のIPv4アドレス、または英数字とコロンで構成されるIPv6アドレスです。これはルーターや通信キャリアに割り当てられたアドレスであり、個人のPCそのものを直接特定するものではありません。

【今回のデータのポイント】
IPアドレスの取得には、世界中で広く利用されている公開API「ipify」（https://www.ipify.org/）を使用しています。具体的には「https://api.ipify.org?format=json」というエンドポイントへリクエストを送り、JSON形式でIPアドレスを受け取る仕組みです。また、取得したIPアドレスはブラウザ上でのみ表示される設計となっており、当サイトのサーバーへの送信・保存は一切行われません。

【免責事項・出典】
IPアドレスの値はご利用のネットワーク環境によって異なり、表示内容の正確性はipify APIの仕様に依存します。本ツールは情報提供を目的としており、取得したIPアドレスの利用に関するいかなる損害についても責任を負いかねます。出典：ipify - A Simple Public IP Address API（https://api.ipify.org/）

よくある質問

表示されたIPアドレスはサーバーに保存されますか？

いいえ、保存されません。取得・表示はすべてブラウザ上のみで完結しており、当サイトのサーバーにIPアドレスが送信・記録されることはありません。

VPNを使っている場合、どのIPアドレスが表示されますか？

VPN接続中はVPNサーバーに割り当てられたグローバルIPアドレスが表示されます。本ツールを使うことで、VPNが正しく機能しているかどうかの簡易確認にも役立てることができます。

スマートフォンで確認した場合、Wi-Fiとモバイルデータ通信でIPアドレスは異なりますか？

はい、異なります。Wi-Fi接続時はルーターに割り当てられたIPアドレス、モバイルデータ通信時はキャリアから割り当てられたIPアドレスがそれぞれ表示されます。

IPアドレスからどこまで個人情報が特定されますか？

グローバルIPアドレスから分かるのは、おおよその地域（都市レベル）や利用しているプロバイダ名程度です。住所や氏名などの個人情報を直接特定することは通常できません。

IPアドレスの取得に使っているipify APIとは何ですか？

ipify（https://www.ipify.org/）は、シンプルにグローバルIPアドレスを返す公開APIサービスです。本ツールではエンドポイント「https://api.ipify.org?format=json」を利用しており、JSON形式でIPアドレスを取得しています。
