📱 QRコード生成ツール

テキスト・URLを入力するとQRコードを即座に生成します。

⬇ ダウンロード (PNG)

ℹ 機能説明

  • テキスト・URL・メールアドレス等あらゆる文字列に対応
  • サイズ変更可能（100px〜1000px）
  • 生成した画像をダウンロード可能
  • クライアントサイドで完結（入力内容はサーバーに送信されません）

📖 使い方

  1. テキストエリアにQRコードに変換したいテキストまたはURLを入力します。
  2. サイズを選択して「生成」ボタンを押します。
  3. QRコード画像が表示されたら「ダウンロード」ボタンで保存できます。
  4. スマートフォンのカメラで読み取ると、入力したURLやテキストを確認できます。
データ出典:
  • https://api.qrserver.com/ (goqr.me QR Code API - 無料・APIキー不要)
QRコード画像はapi.qrserver.com（goqr.me）のAPIを利用してブラウザ上でリアルタイム生成されます。入力したテキストはQRコード生成APIにのみ送信されます。

このツールは、テキストやURLなどの文字列を入力するだけで、QRコードを即座に画像として生成できる無料ツールです。生成されたQRコードはそのままダウンロードして利用できます。

【データの読み方・用語説明】
「サイズ（px）」はQRコード画像の一辺のピクセル数を指します。100pxは主にWeb上の小さな表示向け、300〜500px程度は印刷物への貼り付けに適しており、1000pxは大判印刷やポスター用途に対応します。QRコードの「モジュール」とは白黒のマス目のことで、入力文字数が増えるほどモジュール数が増え、同じサイズでも読み取りにくくなる場合があります。

【今回のデータのポイント】
本ツールが利用しているAPIは「goqr.me QR Code API（https://api.qrserver.com/v1/create-qr-code/）」で、APIキー不要・無料で使用できます。対応する入力形式はテキスト・URL・メールアドレスなどあらゆる文字列で、生成サイズは100pxから1000pxまで指定可能です。また、処理はクライアントサイド（お使いのブラウザ上）で完結するため、入力した内容がサーバーに送信・記録されることはなく、個人情報や機密URLを含む文字列でも安心して利用できます。

【免責事項・出典】
QRコードの生成にはgoqr.me提供の無料公開API（https://api.qrserver.com/）を使用しています。外部APIの仕様変更・障害等により、予告なくサービスが利用できなくなる場合があります。生成したQRコードの利用目的・内容については、ご自身の責任においてご確認ください。

よくある質問

生成できるQRコードのサイズはどのくらいですか？

100pxから1000pxの範囲で自由に指定できます。Web上での表示には100〜300px、印刷物には300〜500px、ポスターなど大判印刷には500px以上が目安です。

入力したURLや文字列はサーバーに保存されますか？

いいえ、保存されません。本ツールはクライアントサイドで処理が完結するため、入力内容がサーバーに送信・記録されることはありません。

URLだけでなく、テキストやメールアドレスにも使えますか？

はい、対応しています。テキスト・URL・メールアドレスなど、あらゆる文字列をQRコード化できます。

生成したQRコードはどのように保存・利用できますか？

生成後に表示されるQRコード画像をダウンロードボタンからPNG形式で保存できます。印刷物・Webサイト・プレゼン資料など幅広い用途でご利用いただけます。

このツールは無料で使えますか？APIキーは必要ですか？

完全無料でご利用いただけます。使用しているgoqr.me QR Code APIはAPIキー不要の公開APIのため、登録やログインも一切不要です。
